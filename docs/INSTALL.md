# Installing DAWASA / DAWASA ස්ථාපනය කිරීම

DAWASA works on Android 7.0 and newer.
DAWASA Android 7.0 සහ ඊට නව අනුවාදවල ක්‍රියා කරයි.

## English

1. Open the DAWASA download page on your phone and tap **Download APK**.
2. Open the downloaded file. If Android says installing from this source is
   not allowed, tap **Settings**, turn on **Allow from this source** for
   your browser or file manager, and go back.
3. Tap **Install**, then **Open**, and follow the welcome guide.

**Check the file (optional):** the download page shows a SHA-256
fingerprint. On a computer, `sha256sum dawasa-*.apk` (Linux),
`shasum -a 256 dawasa-*.apk` (macOS) or
`certutil -hashfile dawasa-*.apk SHA256` (Windows) must print the same
value.

**Updates:** Settings → App updates. DAWASA downloads the new version,
checks it, and Android asks you to confirm. Your data is kept.

**New phone:** Settings → Data → Create backup, save the file somewhere you
can reach from the new phone (Google Drive, e-mail to yourself, a memory
card), install DAWASA on the new phone and choose **Restore from a backup**
on the first screen.

**Important:** your data is stored only on your phone. Uninstalling DAWASA
or clearing its storage deletes it unless you have a backup file.
